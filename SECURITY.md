# Security Policy

The SwiftService maintainers take security issues seriously.

If you believe you have found a vulnerability in SwiftService, please report it
privately so it can be investigated and fixed before public disclosure.

## Supported Versions

Security fixes are prioritized for:

| Branch / Channel | Supported |
| ---------------- | --------- |
| `develop`        | Yes       |
| `Production`     | Yes       |

Older forks or heavily customized deployments may not receive direct patches.

## Reporting a Vulnerability

Please report security issues using one of these private channels:

1. GitHub Security Advisories for this repository:
   [Report a vulnerability](https://github.com/vinaymishraofficial/swiftservice/security/advisories/new)
2. Contact the repository maintainers privately through GitHub

Please include:

- A clear description of the issue
- Steps to reproduce, or a proof of concept if available
- Impact assessment (what an attacker could do)
- Affected versions / commit SHA if known
- Any suggested remediation

## What to Expect

- We will acknowledge valid reports as soon as practical
- We will keep you updated while investigating and preparing a fix
- We ask that you do not publicly disclose the issue until a fix is available
  or we agree on a disclosure timeline

## Out of Scope / Do Not Report Publicly

Do not create a public GitHub issue for:

- Authentication bypasses
- Privilege escalation
- Remote code execution
- Injection flaws
- Exposure of secrets or private data
- Any issue that could put production sites or users at risk

Thank you for helping keep SwiftService and its users safe.
